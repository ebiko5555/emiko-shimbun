# 恵美子新聞

> 煽られずに、世の中を知る。

1日に読む量を22件までに絞り、芸能ゴシップ、炎上、反応集、煽り見出しを除く個人用ニュースサイトです。最初の3件で今日の輪郭をつかみ、読み終えると新しい記事を補充せず静かな終点を表示します。

## できること

- 「今日これだけ」3件と、7カテゴリーの一覧
- 3分／10分の時間別表示、カテゴリー絞り込み
- 保存、既読、非表示と理由、情報源・キーワードのミュート
- ライト／ダーク、文字サイズ3段階、設定初期化
- すべての端末内設定を `localStorage` に保存（ログイン不要）
- 危険なURLを拒否し、外部HTMLを画面へ直接挿入しない
- RSSごとの独立取得、重複排除、除外語判定、カテゴリーの偏りを抑えた22件選定
- 取得に失敗した情報源だけを飛ばし、全件失敗時は前回データを保持
- 日本時間6時・17時の自動更新と手動更新

## 手元で動かす

Node.js 22、pnpm 11、Python 3.12を使います。

```bash
pnpm install
pnpm run dev
```

表示された `http://localhost:3000/` を開きます。

実際のRSSを取得するには:

```bash
pnpm run fetch:news
```

テストとビルド:

```bash
pnpm run test
pnpm run build:pages
```

## 設定を変える

サイト名、説明、終端文、カテゴリー、表示数、除外語、情報源は `public/config/site.json` に集約しています。

- `site`: タイトル、サブタイトル、終端メッセージ
- `limits.total`: 1日に表示する最大件数（初期値22）
- `excludeKeywords`: 見出し・RSS概要に含まれていれば除外する語
- `sources`: RSS情報源。停止時は削除せず `enabled: false` にできます

画面上で追加した個人用ミュート語はブラウザにだけ保存され、公開設定ファイルには書き込まれません。

## GitHub Pagesで公開する

1. このフォルダーを新しいGitHubリポジトリへ置き、既定ブランチを `main` にします。
2. GitHubの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選びます。
3. `main` へpushすると、テストと静的ビルドの後にPagesへ配置されます。
4. **Actions → ニュースを更新 → Run workflow** で、最初の手動取得を確認できます。

公開操作・外部登録はこの制作時点では行っていません。APIキーは不要です。将来AI要約を追加する場合は、キーをGitHub Secretsへ保存し、生成文に `aiGenerated: true` を付けてください。

## データと失敗時の扱い

`scripts/fetch_news.py` がRSS/Atomを取得し、`public/data/news.json` を一時ファイル経由で安全に置き換えます。一つの情報源が失敗しても他を続行し、全件失敗時は既存JSONを変更しません。新規取得が少なすぎる場合は前回成功分を補い、サイトが急に空になるのを防ぎます。

英語のRSSは第1版では原文の短い概要を安全に整形して表示します。AIによる日本語要約は行っておらず、全記事の `aiGenerated` は `false` です。

## 著作権と情報源

記事本文は保存・転載しません。RSS内の見出し、短い概要、媒体名、公開日時、元記事リンクだけを使用します。利用条件を確認した記録と、採用を見送った情報源は [docs/SOURCES.md](docs/SOURCES.md) にあります。

## テスト対象

- HTML除去と概要長の上限
- `javascript:` や `data:` URLの拒否
- 煽り語フィルターとAI生成フラグ
- 類似見出しの重複排除
- 最重要3件のカテゴリー分散

ブラウザの保存内容を消したい場合は、画面の「表示とミュート設定」から「設定を初期化」を選びます。
